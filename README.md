\## 🚀 Esecuzione in Locale

Trattandosi di un sito web statico, puoi testarlo localmente in pochissimi passaggi:



1\. \*\*Clona il repository\*\* sul tuo computer:

&#x20;  ```bash

&#x20;  git clone https://github.com/MM-Technologies-coder/MM-Technologies-coder.github.io.git

&#x20;  ```



2\. \*\*Entra nella cartella\*\* del progetto:

&#x20;  ```bash

&#x20;  cd MM-Technologies-coder.github.io

&#x20;  ```



3\. \*\*Avvia il progetto:\*\*

&#x20;  \* Apri direttamente il file `index.html` con il tuo browser preferito.

&#x20;  \* \*Consigliato:\* Usa l'estensione \*\*Live Server\*\* su VS Code per abilitare l'hot-reloading in tempo reale.
